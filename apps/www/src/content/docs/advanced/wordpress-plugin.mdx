---
title: WordPress Web Analytics Plugin
---

<Steps>

### Download Lucid plugin

Download the Lucid plugin ZIP file from the official WordPress plugin repository or from the Lucid website.

### Install Plugin

1. Log in to your WordPress admin dashboard.
2. Navigate to `Plugins` > `Add New`.
3. Click on the `Upload Plugin` button at the top of the page.
4. Choose the Lucid plugin ZIP file you downloaded and click "Install Now".

### Configure Plugin

1. Once the installation is complete, click on the "Activate Plugin" button.
2. Visit the `Settings` > `Lucid` page in your WordPress admin dashboard.
3. Configure any desired settings.
4. Save the settings, and Lucid will start tracking your website's analytics.

</Steps>

## Usage

Lucid will automatically begin tracking your website's analytics once it is activated. You can view the analytics data by visiting the [Lucid](https://lucid.io) admin dashboard.

From the Lucid dashboard, you can access various reports, including visitor statistics, page views, conversions, user behavior, and performance metrics. Use these insights to optimize your website, improve user engagement, and drive conversions.
